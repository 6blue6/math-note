### 常用不等式

**三角不等式（Triangle Inequality）**

**形式**：对任意实数 / 复数 / 向量 \(a, b\)，有 \(|a + b| $\leq$ |a| + |b|\) 等号成立当且仅当 a 与 b 同方向（实数：\(ab $\geq$ 0\)；复数：辐角相同；向量：共线且同向）。

**均值不等式 (Mean Inequality)**

调和均值（HM）\($\leq$\) 几何均值（GM）\($\leq$\) 算术均值（AM）\($\leq$\) 平方均值（QM），即
$(\frac{n}{\sum \frac{1}{a_i}} \leq \sqrt[n]{\prod a_i} \leq \frac{\sum a_i}{n} \leq \sqrt{\frac{\sum a_i^2}{n}})$

**伯努利不等式（Bernoulli's Inequality）**

基础版：$对实数 x > -1 且整数 n \geq 1，有 (1 + x)^n \geq 1 + nx)$；

加强版（实数指数）：$对实数 x > -1 且 \alpha \leq 0 或 \alpha \geq 1有 ((1 + x)^\alpha \geq 1 + \alpha x；若 0 < \alpha < 1，则不等式反向（(1 + x)^\alpha \leq 1 + \alpha x）。$

- **等号成立条件**：\(x = 0\) 或 \(n = 1\)（基础版）；\(x = 0\) 或 \(\alpha = 0, 1\)（加强版）。
- **用途**：数列极限的估计（如证明 \((1 + $\frac{1}{n})^n$\) 单调递增）、幂函数的放缩。

**柯西 - 施瓦茨不等式（Cauchy-Schwarz Inequality）**

**核心形式（内积空间版）**：对内积空间 V 中的任意向量 \(u, v\)，有
$|(u, v)|^2 \leq (u, u) \cdot (v, v)$

**Jesonn不等式：**

$$ \varphi\Big(\sum_{k=1}^n \lambda_k x_k\Big) \le \sum_{k=1}^n \lambda_k \varphi(x_k) $$

**凸函数**：均值的函数 ≤ 函数的均值

**凹函数**：均值的函数 ≥ 函数的均值

**符号函数（Sign Function，\($\text{sgn}(x)$\)）**

- **定义**：$\\text{sgn}(x) = \begin{cases} 1, & x > 0 \\ 0, & x = 0 \\ -1, & x < 0 \end{cases}$\)；
- **特点**：在 \(x=0\) 处间断（第一类间断点），无法用单个初等函数表示（需注意：\($\text{sgn}(x) = \frac{x}{|x|}\)（\(x \neq 0\)$），但仍需分段补充 \(x=0\) 的定义）；
- **应用**：描述物理量的方向（如速度、力的正负）、控制理论（开关信号）。

**狄利克雷函数（Dirichlet Function，\(D(x)\)）**

- **定义**：$\(\text{Dirichlet}\) 函数是 “处处间断” 的典型例子，定义为：\(D(x) = \begin{cases} 1, & x \in \mathbb{Q} \text{（有理数）} \\ 0, & x \in \mathbb{R}\setminus\mathbb{Q} \text{（无理数）} \end{cases}\)$；

- 性质

  ：

  - 周期性：任何正有理数都是其周期（无最小正周期）；
  - 可积性：在任意区间上**黎曼不可积**（振幅无法通过细分区间减小），但**勒贝格可积**（积分值为 0）；

- **意义**：作为 “反例” 推动积分理论的发展（从黎曼积分到勒贝格积分），揭示函数的复杂性。

**黎曼函数（Riemann Function，\(R(x)\)）**

- **定义**：\($\text{Riemann}$\) 函数是 “仅在无理点连续、有理点间断” 的特殊函数，定义为：$\(R(x) = \begin{cases} \frac{1}{q}, & x = \frac{p}{q} \text{（既约分数，} q > 0\text{）} \\ 0, & x \in \mathbb{R}\setminus\mathbb{Q} \text{或} x=0,1 \end{cases}\)（通常定义在 \([0,1]\) 上，可周期延拓）$；
- **性质**：在 \([0,1]\) 上**黎曼可积**，积分值为 0；
- **意义**：证明 “黎曼可积函数未必连续”，是分析学中研究函数连续性与可积性的重要例子。

**魏尔斯特拉斯函数（Weierstrass Function）**

- **定义：$$ W(x) = \sum_{n=0}^{\infty} a^n \cos\big(b^n \pi x\big) $0 < a < 1,\quad b\in\mathbb{N}^*,\quad ab > 1+\dfrac{3}{2}\pi  $$**
- **性质：**处处连续，处处不可导；
- **意义：**19 世纪前，数学家普遍直观认为：**连续函数除个别点外一定可导**。魏尔斯特拉斯在 1872 年构造出这个函数，颠覆了直观认知，推动**严格数学分析**、函数论、分形几何发展。

## 实数理论

### 实数的构造

- **戴德金分割（Dedekind Cut）**

  由戴德金（Richard Dedekind）于 1872 年提出，核心是 “用有理数的分割定义实数”，避免直接涉及 “极限” 概念，逻辑上最严谨。

  **分割的定义**：将有理数集\($\mathbb{Q}$\)划分为两个非空子集A和B，满足：

  1. 覆盖性：\(A $\cup$ B = $\mathbb{Q}$\)，且\(A$ \cap$ B = $\emptyset$\)；
  2. 有序性：对任意\(a $\in$ A\)、\(b$ \in$ B\)，都有\(a < b\)（A中所有元素小于B中所有元素）。

  **分割的分类**：根据A是否有最大元、B是否有最小元，有理数的分割分为 3 类：

  - 类型 1：A有最大元\(a_0\)（则B无最小元），对应有理数\(a_0\)；
  - 类型 2：B有最小元\(b_0\)（则A无最大元），对应有理数\(b_0\)；
  - 类型 3：$A无最大元且B无最小元（“中间有空隙”），对应**无理数**（如\sqrt{2}的分割：A=\{x \in \mathbb{Q} \mid x \leq 0 \text{ 或 } x^2 < 2\}，B=\{x \in \mathbb{Q} \mid x > 0 \text{ 且 } x^2 > 2\}）$。

  **实数的定义**：所有 “有理数的分割” 构成的集合即为实数集\($\mathbb{R}$\)，其中类型 1/2 对应有理数，类型 3 对应无理数。

- **柯西数列等价类（Cauchy sequences）**

由康托尔（Georg Cantor）于 1872 年提出，核心是 “用有理数的柯西序列定义实数”，更贴合数学分析中 “极限” 的直观理解（因为数列极限是分析学的起点）。

- **柯西序列的定义**：$有理数序列\{x_n\}若满足 “\forall \varepsilon > 0（\varepsilon \in \mathbb{Q}），\exists N \in \mathbb{N}，当(m,n > N时，|x_m - x_n| < \varepsilon”，则称其为$**有理数柯西序列**。
- **有理数的缺陷**：有理数柯西序列的极限不一定是有理数（$如x_n = (1+\frac{1}{n})^n是有理数序列，但极限e不是有理数）$。
- **实数的定义**：将 “等价的有理数柯西序列” 视为同一个实数（等价关系：$\{x_n\} \sim \{y_n\} iff \lim_{n \to \infty} |x_n - y_n| = 0）$，所有等价类构成的集合即为\($\mathbb{R}$\)。

### 性质

**有序域结构**

实数是一个：

- 交换、结合、可逆的**域**
- 并带有一个满足兼容性的**次序**（即 a ≤ b 意味着 b − a 是非负的）

**阿基米德性质（Archimedean Property）**

实数集的 “无界性” 特征，是连接 “有限” 与 “无限” 的关键，表述为：

- $对任意正实数a,b \in \mathbb{R}^+，存在正整数n \in \mathbb{N}，使得na > b。$

### 核心性质（完备性）

| 确界原理（Supremum Principle）           | 非空有上界的实数集必有**最小上界**（上确界）；非空有下界的实数集必有**最大下界**（下确界）。 |
| ---------------------------------------- | ------------------------------------------------------------ |
| 单调有界定理                             | 单调递增且有上界的实数序列必有极限；单调递减且有下界的实数序列必有极限。 |
| 柯西收敛准则                             | 实数序列收敛的充要条件是：该序列是柯西序列（即 “极限存在” 与 “柯西性” 等价）。 |
| 闭区间套定理（Nested Intervals Theorem） | $若\{[a_n, b_n]\}是闭区间序列，满足[a_1, b_1] \supset [a_2, b_2] \supset \cdots且\lim_{n \to \infty} (b_n - a_n) = 0，则存在唯一实数\xi \in \bigcap_{n=1}^\infty [a_n, b_n]。$ |
| 聚点定理（Bolzano-Weierstrass Theorem）  | 有界的实数无限集必有**聚点**（即存在一个点，其任意邻域内都含有该集合的无限多个点）。（有界数列必有子列） |
| 有限覆盖定理（Heine-Borel Theorem）      | 若开区间族\($\mathcal{U}$\)覆盖闭区间\([a,b]\)（即\([a,b] $\subset$$ \bigcup_{U \in \mathcal{U}} U$\)），则存在\($\mathcal{U}$\)的有限子集也覆盖\([a,b]\)。 |

**关键逻辑链**：通常以 “确界原理” 作为 “完备性公理”（原始假设），再依次证明其他 5 个定理与确界原理等价 —— 这是数学分析中 “实数理论” 部分的核心证明训练（如用确界原理证单调有界定理、用闭区间套定理证有限覆盖定理等）。

**Stolz定理**：数列极限的 “洛必达法则”

1. $\frac{\infty}{\infty}型 Stolz 定理（最常用形式）$

设数列\(\{a_n\}\)和\(\{b_n\}\)满足以下 3 个条件：

1. **分母数列严格递增且趋于无穷**：$\(\{b_n\}\)是严格递增数列（即对所有n，\(b_{n+1} > b_n\)），且\(\lim_{n \to \infty} b_n = +\infty\)；$
2. **极限存在或为无穷**：$\(\lim_{n \to \infty} \frac{a_{n+1} - a_n}{b_{n+1} - b_n} = L\)（其中L可以是有限数、\(+\infty\)或\(-\infty\)）；$

则**分子分母数列的极限等于上述差商的极限**： $\lim_{n \to \infty} \frac{a_n}{b_n} = L$

2. \(\frac{0}{0}\)型 Stolz 定理

设数列\(\{a_n\}\)和\(\{b_n\}\)满足以下 3 个条件：

1. **分子分母均趋于 0**：\(\lim_{n \to \infty} a_n = 0\)且\(\lim_{n \to \infty} b_n = 0\)；
2. **分母数列严格递减**：\(\{b_n\}\)是严格递减数列（即对所有n，\(b_{n+1} < b_n\)）；
3. **极限存在或为无穷**：$\(\lim_{n \to \infty} \frac{a_{n+1} - a_n}{b_{n+1} - b_n} = L\)（L为有限数、\(+\infty\)或\(-\infty\)）；$

则同样有：$ \(\lim_{n \to \infty} \frac{a_n}{b_n} = L\)$

### 收敛准则

**海涅定理**：

 $设函数 f(x) 在 x_0 的某去心邻域 U^\circ(x_0) 内有定义，则：\lim\limits_{x \to x_0} f(x) = A（A 为有限数或无穷大）**的充要条件是**：
对任意满足 \lim\limits_{n \to \infty} x_n = x_0\) 且 \(x_n \in U^\circ(x_0)\)（即 \(x_n \neq x_0\)）的数列 \(\{x_n\}\)，都有 \(\lim\limits_{n \to \infty} f(x_n) = A\)。$

**柯西准则：**

设函数 \(f(x)\) 在 \(x_0\) 的某去心邻域 \($U^\circ(x_0)$\) 内有定义，则：\($\lim\limits_{x \to x_0} f(x)$ 存在（且为有限数）**的充要条件是**：
对任意给定的 \($\varepsilon$ > 0\)，存在 \($\delta$ > 0\)，使得对任意 \($x_1, x_2 \in U^\circ(x_0)$\)，当 \($0 < |x_1 - x_0| < \delta$\) 且 \($0 < |x_2 - x_0| < \delta$\) 时，有 \(|f(x_1) - f($x_2)| < \varepsilon$\)。

**单调有界**：

- 若 \(f(x)\) 在 \((a, x_0)\) 内**单调递增且有上界**（或单调递减且有下界），则 \\$lim_{x \to x_0^-} f(x)$\) 存在；

- 若 \(f(x)\) 在 \((x_0, b)\) 内**单调递增且有下界**（或单调递减且有上界），则 \($\lim_{x \to x_0^+} f(x)$\) 存在。

### 无穷量与阶

**定义**

-**无穷小量的定义**：设函数\(f(x)\)在\(x $\to$ x_0\)（或\($x \to \infty$）的某去心邻域内有定义，若\($\lim_{x \to x_0} f(x) = 0$\)，则称\(f(x)\)是当\($x \to x_0$\)时的**无穷小量**，简称 “无穷小”。

-**无穷大量的定义**：设函数\(f(x)\)在\(x $\to x_0$\)的某去心邻域内有定义，若对任意给定的正数M（无论多大），总存在\($\delta > 0$\)，使得当\($0 < |x - x_0| < \delta$\)时，有\(|f(x)| > M\)，则称\(f(x)\)是当\($x \to x_0$\)时的**无穷大量**，简称 “无穷大”，记为\($\lim_{x \to x_0} f(x) = \infty$\)。

## 函数的连续性

### 定义

**点连续**：

1. **\($f(x_0)$\) 存在**：函数在 \(x_0\) 处有确定的函数值（无 “无定义点”）；
2. **\($\lim\limits_{x \to x_0} f(x)$\) 存在**：函数在 \(x_0\) 处的极限存在（左极限 = 右极限，无 “跳跃间断”“无穷间断” 等）；
3. **\($\lim\limits_{x \to x_0}$ f(x) = f($x_0$)\)**：函数在 \(x_0\) 处的极限值等于该点的函数值（无 “可去间断”，即极限与函数值 “重合”）。

衍生出**左连续**和**右连续**的定义：

- **左连续**：若 \($\lim\limits_{x \to x_0^-} f(x) = f(x_0)$\)（左侧极限等于函数值），则称 \(f(x)\) 在 \($x_0$\) 处左连续；
- **右连续**：若 \($\lim\limits_{x \to x_0^+} f(x) = f(x_0)$\)（右侧极限等于函数值），则称 \(f(x)\) 在 \($x_0$\) 处右连续。

**区间连续**：

**开区间 \((a, b)\) 内连续**：若 \(f(x)\) 在开区间 \((a, b)\) 内的**每一点**都连续，则称 \(f(x)\) 在 \((a, b)\) 内连续；

**闭区间 \([a, b]\) 上连续**满足：

- 在开区间 \((a, b)\) 内连续；
- 在左端点 a 处**右连续**（\($\lim\limits_{x \to a^+} f(x) = f(a)$）；
- 在右端点 b 处**左连续**（\($\lim\limits_{x \to b^-} f(x) = f(b)$）； 则称 \(f(x)\) 在闭区间 \([a, b]\) 上连续。

**间断点**：

连续满足的条件：在$x_0$处有意义，左右极限存在且等于f($x_0$)。

**第一类间断点（左右极限都存在）**：

- **可去间断点**

左极限 = 右极限（即 \($\lim\limits_{x \to x_0} f(x) = A$\)，**极限存在**），但满足以下两种情况之一：

1. \(f(x_0)\) 无定义（函数在 \(x_0\) 处 “缺失”）；
2. \(f(x_0)\) 有定义，但 \(f(x_0) $\neq$ A\)（函数值与极限值不相等）。

- **跳跃间断点**

左极限 ≠ 右极限（即 \($\lim\limits_{x \to x_0^-} f(x) = A$\)，\($\lim\limits_{x \to x_0^+} f(x) = B$\)，且 \(A$ \neq$ B\)），无论 \(f(x_0)\) 是否有定义，均为跳跃间断点。

**第二类间断点**：

\($\lim\limits_{x \to x_0^-} f(x) 和 \lim\limits_{x \to x_0^+} f(x)$\) 中**至少有一个不存在**（包括极限为 \($\infty$\) 或振荡无固定趋势的情况）。

**一致连续：**

设f为定义在区间I上的函数，若对于任给的$\varepsilon$>0,存在$\delta$ =$\delta$($\varepsilon$)>0,使得对于任何$x^1$ $x^2$ $\in$ I,只要｜$x^1$ - $x^2$｜< $\delta$,就有｜f($x^1$)-f($x^2$) ｜<$\varepsilon$.则称f在区间I上一致连续。

### 性质

**点连续性质:**

- 四则运算
- 局部有界性
- 局部保号性
- 复合运算

**区间连续性质:**

- 最值定理（闭区间必有最大值与最小值）
- 介值性定理（设函数 \(f(x)\) 在**闭区间 \([a, b]\)** 上**连续**，且 \(f(a)$ \neq $f(b)\)。若 C 是介于 \(f(a)\) 和 \(f(b)\) 之间的任意一个实数（即 \($\min\{f(a), f(b)\} < C < \max\{f(a), f(b)\}$），则**至少存在一个点 \($\xi$$ \in$ (a, b)\)**，使得 \(f($\xi$) = C\)。当C为零时，为零点存在性定理。）
- 反函数连续性定理 若函数f在[a,b]上严格单调并连续，则反函数$f^-1$在其定义域上连续。
- 一致连续性定理(cantor) 若函数f在闭区间[a,b]上连续，则f在[a,b]上一致连续。
- 对**任意区间 I**（开区间、无限区间等皆可）上的函数 \(f(x)\)，一致连续的充要条件是： **对区间 I 内的任意两个序列 \(\{$x_n$\}\) 和 \(\{$y_n$\}\)，若 \($\lim\limits_{n \to \infty} (x_n - y_n) = 0$\)，则 \($\lim\limits_{n \to \infty} [f(x_n) - f(y_n)] = 0$\)**。
- 对于f(x)在开区间（a,b）连续，则f(x)在(a,b)上一致连续的充要条件：f在a的右极限，b的左极限存在且有限。

**初等函数连续性质：**

- 任何初等函数都属在其定义区间上的连续函数。

## 微分学

### 定义

**微分**：

设函数 \(y = f(x)\) 在点 \($x_0$\) 的某个邻域内有定义，若函数在 \($x_0$\) 处的增量 \($\Delta y = f(x_0 + \Delta x$) - f($x_0$)\) 可以表示为：\($\Delta y = A \cdot \Delta x + o(\Delta x$)\) 其中：

- A 是与 \($\Delta$ x\) 无关的常数（仅与函数 \(f(x)\) 和点 \($x_0$\) 有关）；
- \(o($\Delta$ x)\) 是当 \($\Delta x \to 0$\) 时，比 \(**$\Delta$** x\) 更高阶的无穷小量（即 \($\lim_{\Delta x \to 0} \frac{o(\Delta x)}{\Delta x} = 0$\)）；

则称函数 \(y = f(x)\) 在点 \(x_0\) 处**可微**，且把 \(A$ \cdot \Delta x$\) 称为函数 \(f(x)\) 在点 \(x_0\) 处的**微分**，记作 \(dy|_{x=x_0}\) 或 \(df(x_0)\)，即：\(dy|_{x=x_0} = A$ \cdot \Delta x$\)。dy称为线性主部。如果f在区间的每一点都可微，则在区间可微。

微分的本质是对函数增量 \($\Delta$ y\) 的 “简化近似”：

- **线性主部**（\(A $\cdot \Delta x$\)）：是 \($\Delta$ y\) 中与 \($\Delta$ x\) 成线性关系的部分，也是增量的 “主要贡献者”；
- **高阶无穷小**（\(o($\Delta$ x)\)）：当 \($\Delta$ x\) 很小时，这部分的影响可以忽略不计，是近似的 “误差项”。

**导数**：

设函数 \(y = f(x)\) 在点 \($x_0$\) 的某邻域内有定义，若极限：$\(\boxed{f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}}\) $存在，则称 \(f(x)\) 在 \($x_0$\) 处**可导**，该极限值即为 \(f(x)\) 在 \(x_0\) 处的导数，记为 \($f'(x_0)\)、\(y'|_{x=x_0}\) 或 \(\frac{dy}{dx}|_{x=x_0}$\)。

若该极限不存在，则称 \(f(x)\) 在 \($x_0$\) 处**不可导**.

**区间可导**：f在区间每一点都可导，当闭区间时，左（右）端点右（左）导存在。

**稳定点**：

对于函数 \(y = f(x)\)，若在点 \($x_0$\) 处满足以下两个条件：

1. 函数 \(f(x)\) 在 \($x_0$\) 处**可导**（即导数 \(f'($x_0$)\) 存在，排除了不可导点）；
2. 该点的导数等于 0，即 \($\boxed{f'(x_0) = 0}$\)；

则称点 \(($x_0$, f($x_0$))\) 是函数 \(f(x)\) 的**稳定点**（也常被称为 “驻点”，二者在微积分中含义完全等价）。

**高阶微分与导数**：

$设 \((n-1)\) 阶微分 \(d^{n-1} y = f^{(n-1)}(x) dx^{n-1}\)，则 n 阶微分是 \((n-1)\) 阶微分的微分：\(d^n y = d(d^{n-1} y) = d(f^{(n-1)}(x) dx^{n-1}) = f^{(n)}(x) dx \cdot dx^{n-1} + f^{(n-1)}(x) \cdot d(dx^{n-1})\)$
$因 \(dx^{n-1} = (dx)^{n-1}\) 是常数（\(d(dx^{n-1}) = 0\)），故化简为\(d^n y = f^{(n)}(x) \cdot dx^n\)$.

$设 \(f(x)\) 的 \((n-1)\) 阶导函数 \(f^{(n-1)}(x)\) 在 \(x_0 \in I_{n-1}\) 处可导（\(n \geq 2\)，\(I_{n-1} \subseteq I_{n-2} \subseteq \dots \subseteq I\)）$，则称 \(f(x)\) 在 \(x_0\) 处 **n 阶可导 **，记为$\(f^{(n)}(x_0) = \lim_{\Delta x \to 0} \frac{f^{(n-1)}(x_0 + \Delta x) - f^{(n-1)}(x_0)}{\Delta x}\)n 阶导函数记为 \(f^{(n)}(x)\)、\(y^{(n)}\) 或 \(\frac{d^n y}{dx^n}\)（注意：\(n \geq 3\) 时不用 \('''\)，而用上角标 \((n)\)）$

### 罗尔中值定理（Rolle）

**内容：**

若函数 f(x) 满足以下**三个条件**：

1. **闭区间连续**：f(x) 在闭区间 [a,b] 上**连续**；
2. **开区间可导**：f(x) 在开区间 (a,b) 内**处处可导**；
3. **端点值相等**：f(a)=f(b)；

则**至少存在一点** ξ∈(a,b)，使得：f′(ξ)=0

### 拉格朗日中值定理（Lagrange）

**内容：**

设函数 f(x) 满足：

1. 在闭区间 [a,b] 上**连续**；
2. 在开区间 (a,b) 内**可导**；

则至少存在一点 ξ∈(a,b)，使得：

f(b)−f(a)=f′(ξ)(b−a)

变形（常用形式）：

f′(ξ)=$\frac{f(b)−f(a)}{b-a}$

**推论 1：导函数恒为零 ⟺ 函数为常函数**

f′(x)≡0, ∀x∈(a,b)⟹f(x)≡C

**推论 2：两函数导数相等 ⟺ 两函数差为常数**

f′(x)≡g′(x)⟹f(x)−g(x)≡C

**推论3: 一阶导数与单调性**

**推论4: 二阶导数与凹凸性与Jensen不等式**

**推论5: 导数极限定理** 

设：

1. f(x) 在 x0 的**某邻域** U(x0) 内**连续**；
2. 在去心邻域 U˚(x0) 内**可导**；
3. 极限$ \lim\limits_{x \to x_0} f'(x))$=A 存在（有限 / 无穷都可）

f′(x0)=limx→x0f′(x)=A

设 f(x) 在 [a,b] 上**可导**（端点为单侧可导）

则：**导函数 \**f′(x)\** 在 \**[a,b]\** 上具有介值性**

>

> \>f′(ξ)=μ>

### 不定积分

#### 定义

**不定积分：**

设函数 f(x) 定义在**区间 I**上，

若存在函数 F(x)，满足：

∀x∈I,F′(x)=f(x)

则称：

1. F(x) 为 f(x) 在区间 I 上的**一个原函数**；
2. f(x)在区间 I上的全体原函数，称为 f(x)的不定积分，记作：**∫f(x)dx**

**有理函数：**

**两个多项式的商**，称为**有理函数**：

R(x)=Q(x)P(x)

- P(x)：分子多项式
- Q(x)：分母多项式，且 Q(x)!≡0

#### 性质

**求导与不定积分互为逆运算**

**一切初等函数都可导数，导数仍然是初等函数，不一定可积为初等函数**

**原函数存在定理：**

若 f(x) 在区间 I 上**连续**，则 f(x) 在 I 上一定存在原函数。

**同一个·函数的原函数之间只相差一个常数**

**∫(k1f±k2g)dx=k1∫fdx±k2∫gdx**

**第一换元积分法：**

设：

1. ∫f(u)du=F(u)+C，即 F′(u)=f(u)
2. u=φ(x) 可导

则**第一换元积分公式**：**∫f(φ(x))φ′(x)dx=∫f(u)du=F(u)+C=F(φ(x))+C**

**第二类换元积分法：**

设：

1. x=ψ(t) 单调、可导；
2. ψ′(t)\\=0；
3. f[ψ(t)]ψ′(t) 存在原函数。

则**∫f(x)dx=∫f[ψ(t)]ψ′(t)dt**

**分部积分法：**

已知两个可导函数 u(x),v(x) 的**乘积求导法则**：

(u⋅v)′=u′v+uv′

移项得：

uv′=(uv)′−u′v

两边同时求**不定积分**：

∫uv′dx=uv−∫u′vdx

**有理函数部分分式分解定理：**

任何一个真分式 $\frac{P(x)}{Q(x)} $（其中 P,Q 是实系数多项式， $\deg P < \deg Q） $，都可以唯一地分解成以下两类简单分式之和：

1. 一次因式对应的项
   若分母有因子 (x-a)^k，则分解后含有：
    $\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_k}{(x-a)^k} $
   其中 A_i 是实常数。
2. 二次不可约因式对应的项
    $若分母有因子 (x^2+px+q)^m（其中 p^2-4q<0，即判别式负，实数范围内不能再分解），则分解后含有：
   \frac{B_1 x + C_1}{x^2+px+q} + \frac{B_2 x + C_2}{(x^2+px+q)^2} + \cdots + \frac{B_m x + C_m}{(x^2+px+q)^m}
   其中 B_i, C_i 是实常数。 $

**可化为有理函数不定积分：**

- 有理分式本身

- R(sinx,cosx) 三角有理式 

- 一次分式根式 $\sqrt{\frac{ax+b}{cx+d}}$

- 二次根式 $\sqrt{ax^2+bx+c}$

- R(ex)、双曲有理式

**切比雪夫二项微分式可积性判别定理：**

对于**二项微分式积分**：

∫xm(a+bxn)pdx

其中 m,n,p 为**有理数**，a,b 为常数且 b\\=0，则该积分**能用初等函数表示**的**充要条件**是：

以下三个数中**至少有一个为整数**：

1. p
2. nm+1
3. nm+1+p

**刘维尔积分理论**

**若 \(f(x)\) 在区间 I 上存在原函数 \(F(x)\)，则 \(f(x)\) 在 I 内不存在第一类间断点（跳跃、可去间断点）；允许有无穷间断点、振荡间断点（第二类间断点）。**

#### 典例

**适合分部积分类型：**

- 幂函数 × 指数函数 后移非幂
- 幂函数 × 对数函数 后移幂
- 幂函数 × 三角函数  后移非幂
- 幂函数 × 反三角函数 后移幂

### 定积分

#### 定义

**定积分：**

设函数 f(x) 定义在**闭区间** [a,b] 上的**有界函数**。

对 [a,b] 插入分点：

a=x0<x1<x2<⋯<xn−1<xn=b

称 P={x0,x1,…,xn} 为 [a,b] 的一个**分割**。

记第 k 个小区间：

Δxk=xk−xk−1,k=1,2,…,n

分割的**模（细度）**：

∥P∥=max{Δx1,Δx2,…,Δxn}

在每个小区间 [xk−1,xk] 上任取一点 ξk∈[xk−1,xk]，作和：

SP=∑k=1nf(ξk)Δxk

称 SP 为函数 f 对应分割 P 的**黎曼和**。

若存在常数 I∈R，满足：

对 **任意**ε>0，都 **存在**δ>0，使得对 [a,b] 的 **任意** 分割 P，只要分割模满足 ∥P∥<δ，且对每个小区间内 **任意** 取点 $ξ_k∈[x_{k−1},x_k]$，都有：

$\sum_{k=1}^n(ξ_k)Δx_k−I∣<ε$

则称函数 f(x) 在 [a,b] 上**黎曼可积**，极限值 I 称为 f 在 [a,b] 上的**定积分**，记作：

$\int_{a}^{b}f(x)dx=I$

**达布和：**

设函数 f(x) 在闭区间 [a,b]**有界**。

对 [a,b] 作**分割**：

π:a=x0<x1<x2<⋯<xn=b

记每个小区间 Δxi=xi−xi−1。

在每个小区间 [xi−1,xi] 上：

mi=infx∈[xi−1,xi]f(x)下确界

Mi=supx∈[xi−1,xi]f(x)上确界

达布下和（小和）

s(π)=∑i=1nmiΔxi

用每个区间上**函数最小值的确界**乘区间长度求和。

达布上和（大和）

S(π)=∑i=1nMiΔxi

用每个区间上**函数最大值的确界**乘区间长度求和。

- 下积分：所有达布下和的上确界 $\int_{a}^{b}f(x)dx$=supπs(π)
- 上积分：所有达布上和的下确界 $\int_{a}^{b}f(x)dx$=infπS(π)

**区间上的内积：**

⟨f,g⟩=$\int_a^b f(x)g(x)\mathrm{d}x$

**正交：**

⟨f,g⟩=$\int_a^b f(x)g(x)\mathrm{d}x=0$

**正交函数列：**

设函数列

{φn(x)},n=1,2,3,…

每个 φn(x) 都在 [a,b] 上可积，且满足：

$欧氏空间 \(\mathbb R^n\) 中正交向量：\(x\perp y\iff x\cdot y=0\)，任意向量可正交分解；$

$函数空间 \(L^2[a,b]\) 是**无穷维线性空间**，函数看成 “无穷维向量”，积分内积替代点积，正交函数列就是无穷维空间里一组正交基。$

(1-x^2)y'' - 2xy' + n(n+1)y = 0

$P_n(x) = \frac{1}{2^n n!}\frac{d^n}{dx^n}\left[(x^2-1)^n\right]$

$\int_{-1}^{1} P_m(x)P_n(x) dx = \begin{cases} 0, & m\neq n \\ \dfrac{2}{2n+1}, & m=n \end{cases}$

#### 性质

**函数可积，则必定有界**

**对同一分割：s(π)≤任意黎曼和≤S(π)**

**加细分割（在原有分割里多加分点）：**

- 下和不减：s 变大或不变
- 上和不增：S 变小或不变

**达布定理：**

对**有界函数**f 在 [a,b]，分割 π 的模 ∥π∥→0 时：

lim∥π∥→0s(π)=supπs(π)  lim∥π∥→0S(π)=infπS(π)

即：**达布下和 / 上和的极限 = 下积分 / 上积分**。

**有界函数f(x)可积的第一充要条件：**

**下积分所有达布下和的上确界=上积分所有达布上和的下确界（达布和用区间上函数的上下确界代替黎曼和里任意取的点，把 “随机求和” 变成 “确定的上下界求和”，用确界和分割严格建立起定积分理论，是数分里定义黎曼积分的核心工具。）**

 **第二充要条件：**

ωi=Mi−mi

lim∥π∥→0∑i=1nωiΔxi=0

通俗：**分割足够细时，总面积的波动可以任意小，存在一个分割等价于任意一个分割**。

**第三充要条件：**

**f在 [a,b]上的**不连续点集是**零测集**

**闭区间的连续函数一定可积**

**闭区间上的单调函数一定可积**

**闭区间上只有有限个不连续点一定可积**

**线性性质：**

$$ \int_a^b \big(\alpha f(x)+\beta g(x)\big)\mathrm{d}x =\alpha\int_a^b f(x)\mathrm{d}x + \beta\int_a^b g(x)\mathrm{d}x $$

**若 f,g 在 [a,b] 可积，且**几乎处处相等**（仅零测集上不等），则：**

$\int_{a}^{b}f(x)dx=\int_{a}^{b}g(x)dx$

**f,g可积，f*g也可积**

**保序性：**

$$ f(x)\le g(x) \implies \int_a^b f(x)\mathrm{d}x \le \int_a^b g(x)\mathrm{d}x $$

**绝对可积性**

$$ \left|\int_a^b f(x)\mathrm{d}x\right| \le \int_a^b |f(x)|\mathrm{d}x $$

**区间可积性（充要）：**

$$ \int_a^b f(x)\mathrm{d}x =\int_a^c f(x)\mathrm{d}x + \int_c^b f(x)\mathrm{d}x $$

**积分第一中值定理：**

f,g可积，g不变号，f连续，否则$f(\xi)$为确界的间值

$$ \exists\xi\in[a,b],\ \int_a^b f(x)g(x)\mathrm{d}x = f(\xi)\int_a^b g(x)\mathrm{d}x $$

$$ \exists\xi\in[a,b],\ \int_a^b f(x)\mathrm{d}x = f(\xi)(b-a)(g(x)=1) $$

条件： 1. $f\in R[a,b]$； 2. $g(x)$ 在 $[a,b]$ 上单调（无正负限制）。 结论：$\exists \xi\in[a,b]$，满足 $$ \int_{a}^{b}f(x)g(x)\mathrm{d}x = g(a)\int_{a}^{\xi}f(x)\mathrm{d}x + g(b)\int_{\xi}^{b}f(x)\mathrm{d}x $$

**赫尔德不等式：**

$$ \dfrac{1}{p} + \dfrac{1}{q} = 1,\quad p>1,\ q>1 $$ 

$$ \sum_{k=1}^n |a_k b_k| \le \left( \sum_{k=1}^n |a_k|^p \right)^{\frac{1}{p}} \left( \sum_{k=1}^n |b_k|^q \right)^{\frac{1}{q}} $$

$(\int_{a}^{b}f(x)g(x)dx)^2<=\int_{a}^{b}f^2(x)dx\int_{a}^{b}g^2(x)dx$

**分部积分法：**

$\int_{a}^{b}udv=uv|^b_a-\int_{a}^{b}vdu$

**换元积分法：**

设：

1. $(f(u)\ 在区间 I 上**连续**；$
2. $(\varphi(x)\) 在闭区间 \([a,b]\) 上**连续可导**；$

### 微积分基本定理

#### 微积分第一基本定理（变上限积分求导）

设函数 f(x) 在闭区间 [a,b] 上**可积**，定义变上限积分函数：

$\int_{a}^{x}f(t)dt$,x∈[a,b]

1. F(x) 在 [a,b] 上**连续**；

2. 若 f(x)在 x0∈(a,b)连续，则 F(x)在 x0 处可导，且： 

   F′(x0)=f(x0)

**核心意义**：**连续函数的变上限积分，就是它的一个原函数**，积分可以生出原函数。

#### 微积分第二基本定理（牛顿 - 莱布尼茨公式）

设 f(x) 在 [a,b] 上**可积**，且 F(x) 是 f(x) 在 [a,b] 上的**任意一个原函数**（即 F′(x)=f(x)），则：

=F(b)−F(a)

常记作：

$\int_{a}^{b}f(x)dx$=F(x)|ab

**核心意义**：定积分的计算，转化为**求原函数再代上下限**，把求和取极限的积分，变成了求导逆运算。

### 反常积分

#### 定义

**无穷积分：**

若 $\forall A>a$，定积分 $\displaystyle\int_{a}^{A}f(x)\mathrm dx$ 存在。 若极限 $$ \lim_{A\to+\infty}\int_{a}^{A}f(x)\mathrm dx $$ 存在且为有限实数，则称无穷积分 $\displaystyle\int_{a}^{+\infty}f(x)\mathrm dx$ **收敛**，并定义 $$ \int_{a}^{+\infty}f(x)\mathrm dx \triangleq \lim_{A\to+\infty}\int_{a}^{A}f(x)\mathrm dx $$ 若上述极限不存在（趋于 $\pm\infty$、振荡无极限），称该无穷积分**发散**。

**瑕积分：**

若函数 $f(x)$ 在区间内某点附近趋于无穷大，该点称为**瑕点（奇点）**； 瑕积分本质：把含瑕点的区间截断挖去瑕点附近小区间，先做正常定积分，再对截断端点取极限。

$$ \int_{a}^{b} f(x)\mathrm dx \triangleq \lim_{\varepsilon\to 0^+} \int_{a}^{b-\varepsilon} f(x)\mathrm dx $$ - 极限存在且为有限实数：称瑕积分**收敛**； - 极限不存在（$\pm\infty$、振荡）：瑕积分**发散**。

**柯西主值(CPV）：**

有些反常积分按照严格定义是发散的，但沿着**对称方式取极限**可以得到一个有限数值，这个强行对称截断算出的有限值就叫**柯西主值**。 严格反常积分收敛 $\implies$ 柯西主值存在且相等； 柯西主值有限 $\nRightarrow$ 原反常积分收敛。

$$ \int_{-\infty}^{+\infty}f(x)\mathrm dx \triangleq \lim_{B\to-\infty}\int_{B}^{c}f(x)\mathrm dx +\lim_{A\to+\infty}\int_{c}^{A}f(x)\mathrm dx $$ 要求左右两个极限**各自独立趋于无穷**时都有限。

左右两端用同一个参数同步趋向无穷，对称截取区间 $[-A,A]$： $$ \mathrm{P.V.}\int_{-\infty}^{+\infty}f(x)\mathrm dx \triangleq \lim_{A\to+\infty}\int_{-A}^{A}f(x)\mathrm dx $$

**绝对收敛：若取绝对值后的反常积分收敛，则称原反常积分绝对收敛。**

**条件收敛：$ \int_{a}^{+\infty}f(x)\mathrm{d}x \text{ 收敛},\quad \int_{a}^{+\infty}|f(x)|\mathrm{d}x \text{ 发散} $**

#### 性质

**无穷积分柯西收敛准则：**

$$ \int_{a}^{+\infty}f(x)\mathrm{d}x \text{ 收敛} \iff \forall \varepsilon>0,\exists X>a,\forall A_2>A_1>X,\ \left|\int_{A_1}^{A_2}f(x)\mathrm{d}x\right|<\varepsilon $$

**无穷积分绝对收敛则一定收敛**

**非负数无穷积分判别：**

若存在 $X\ge a$，当 $x\ge X$ 时满足： $$ 0\le f(x)\le g(x) $$ 1. $\displaystyle\int_a^{+\infty}g(x)dx$ 收敛 $\implies \displaystyle\int_a^{+\infty}f(x)dx$ 收敛； 2. $\displaystyle\int_a^{+\infty}f(x)dx$ 发散 $\implies \displaystyle\int_a^{+\infty}g(x)dx$ 发散。

$$ \lim_{x\to+\infty}\frac{f(x)}{g(x)} = \lambda,\quad 0\le\lambda\le+\infty $$ 1. $0<\lambda<+\infty$：$\displaystyle\int_a^{+\infty}f(x)dx$ 与 $\displaystyle\int_a^{+\infty}g(x)dx$ 同敛散； 2. $\lambda=0$：$\displaystyle\int_a^{+\infty}g(x)dx$ 收敛 $\implies \displaystyle\int_a^{+\infty}f(x)dx$ 收敛； 3. $\lambda=+\infty$：$\displaystyle\int_a^{+\infty}g(x)dx$ 发散 $\implies \displaystyle\int_a^{+\infty}f(x)dx$ 发散。

$$ \int_a^{+\infty}\frac{1}{x^p}dx \begin{cases} \text{收敛},& p>1\\ \text{发散},& p\le 1 \end{cases}\quad(a>0) $$ 日常解题绝大多数场景均以 $\dfrac{1}{x^p}$ 作为比较基准。

存在 $X>0,\ C>0$，对任意 $x\ge X$： 1. $0\le f(x)\le \dfrac{C}{x^p},\ p>1 \implies \displaystyle\int_a^{+\infty}f(x)dx$ 收敛； 2. $f(x)\ge \dfrac{C}{x^p},\ p\le 1 \implies \displaystyle\int_a^{+\infty}f(x)dx$ 发散。

$$ \lim_{x\to+\infty} x^p f(x) = \lambda $$ 1. $0\le\lambda<+\infty,\ p>1$：积分收敛； 2. $0<\lambda\le+\infty,\ p\le 1$：积分发散。

**一般无穷积分判别：**

**Abel:**

1. $\displaystyle\int_{a}^{+\infty}f(x)\mathrm{d}x$ 收敛； 2. $g(x)$ 在 $[a,+\infty)$ 单调有界； $\implies \displaystyle\int_{a}^{+\infty}f(x)g(x)\mathrm{d}x$ 收敛。

**Dirichlet 判别法:**

1. $\displaystyle\int_{a}^{A}f(x)\mathrm{d}x$ 关于 $A$ 在 $[a,+\infty)$ 上有界； 2. $g(x)$ 在 $[a,+\infty)$ 单调且 $\displaystyle\lim_{x\to+\infty}g(x)=0$； $\implies \displaystyle\int_{a}^{+\infty}f(x)g(x)\mathrm{d}x$ 收敛。

**瑕积分柯西判别：**

$\displaystyle\int_{a}^{b}f(x)\mathrm{d}x$ 收敛 $$ \iff \forall \varepsilon>0,\exists \delta\in(0,b-a),\forall u_1,u_2\in(b-\delta,b),\left|\int_{u_1}^{u_2}f(x)\mathrm{d}x\right|<\varepsilon $$

**非负数瑕积分判别：**

若 $0\le f(x)\le g(x),\ x\in[a,b)$： 1. $\displaystyle\int_{a}^{b}g(x)\mathrm{d}x$ 收敛 $\implies \displaystyle\int_{a}^{b}f(x)\mathrm{d}x$ 收敛； 2. $\displaystyle\int_{a}^{b}f(x)\mathrm{d}x$ 发散 $\implies \displaystyle\int_{a}^{b}g(x)\mathrm{d}x$ 发散。

$$ \lim_{x\to b^-}\frac{f(x)}{g(x)}=l,\quad g(x)>0 $$ 1. $0<l<+\infty$：$\displaystyle\int_{a}^{b}f(x)\mathrm{d}x$ 与 $\displaystyle\int_{a}^{b}g(x)\mathrm{d}x$ 同敛散； 2. $l=0$：$\displaystyle\int g$ 收敛 $\implies \displaystyle\int f$ 收敛； 3. $l=+\infty$：$\displaystyle\int g$ 发散 $\implies \displaystyle\int f$ 发散。

$$ \int_{a}^{b}\frac{1}{(b-x)^p}\mathrm{d}x $$ - $p<1$：积分收敛； - $p\ge1$：积分发散。

$$ \lim_{x\to b^-} (b-x)^p f(x)=l $$ 1. $p<1,\ 0\le l<+\infty$：$\displaystyle\int_{a}^{b}f(x)\mathrm{d}x$ 收敛； 2. $p\ge1,\ 0<l\le+\infty$：$\displaystyle\int_{a}^{b}f(x)\mathrm{d}x$ 发散。

**一般瑕积分判别：**

**Abel:**

条件： 1. $\displaystyle\int_{a}^{b}f(x)\mathrm{d}x$ 收敛； 2. $g(x)$ 在 $[a,b)$ 单调有界； 结论：$\displaystyle\int_{a}^{b}f(x)g(x)\mathrm{d}x$ 收敛。

**Dirichlet判别法:**

条件： 1. $\displaystyle\int_{a}^{u}f(x)\mathrm{d}x$ 对 $u\in[a,b)$ 一致有界； 2. $g(x)$ 在 $[a,b)$ 单调，且 $\lim\limits_{x\to b^-}g(x)=0$； 结论：$\displaystyle\int_{a}^{b}f(x)g(x)\mathrm{d}x$ 收敛。

## 数项级数

### 定义

**数项级数：**

把该无穷数列的所有项依次形式相加： $$ \sum_{n=1}^{\infty} u_n = u_1 + u_2 + u_3 + \dots + u_n + \dots $$ 这个无穷求和表达式就叫做**数项无穷级数**，简称**数项级数**。 - $u_n$：级数的**通项（一般项）**； - $u_1$：首项； - 下标 $n$ 从 $1$ 开始，也可根据需求改成从 $0,2$ 等起始。

若部分和数列 $\{S_n\}$ 存在有限极限： $$ \lim_{n\to\infty} S_n = S \in \mathbb{R} $$ 则称数项级数 $\displaystyle\sum_{n=1}^{\infty} u_n$ **收敛**，$S$ 叫做级数的**和**，记作： $$ \sum_{n=1}^{\infty} u_n = S $$

若 $\lim\limits_{n\to\infty}S_n$ 不存在（极限为 $+\infty,-\infty$ 或是震荡无极限），称级数发散，此时无穷求和没有确定数值。

**余和级数：**

设数项级数 $$ \sum_{k=1}^{\infty} u_k = u_1+u_2+u_3+\cdots+u_n+\cdots $$ 记前 $n$ 项部分和： $$ S_n = \sum_{k=1}^n u_k $$ 定义**余项**： $$ R_n = \sum_{k=n+1}^{\infty} u_k $$ 这个从第 $n+1$ 项开始往后的无穷级数 $$ \sum_{k=n+1}^{\infty} u_k $$ 就称作原级数的**余和级数**，简称余项级数。

**有界数列的极限点：**

有界数列的一个收敛子列的极限（可以包括无穷）称为它的一个极限点

$\xi$ 是 $\{x_n\}$ 的极限点 $\iff$ 存在 $\{x_n\}$ 的子列 $\{x_{n_k}\}$，使得 $$ \lim_{k\to\infty} x_{n_k} = \xi $$

数列全体项被限制在有限闭区间之内，项的数量无穷多，必然有无穷多项无限聚集在某一点附近，该聚集中心即为极限点。

设实数列 $\{x_n\}$，实数 $\xi$ 称为该数列的**极限点（聚点）**，满足： $$ \forall \varepsilon>0,\; (\xi-\varepsilon,\xi+\varepsilon)\setminus\{\xi\} $$ 此去心邻域内包含数列 $\{x_n\}$ 的无穷多项。

记数列全部极限点构成集合 $E$，则： $$ \begin{aligned} \varlimsup_{n\to\infty}x_n &= \sup E\\ \varliminf_{n\to\infty}x_n &= \inf E \end{aligned} $$ 1. 上极限：全体极限点里取值最大的数； 2. 下极限：全体极限点里取值最小的数；

**上下极限的另一种定义：**

记尾部上确界与尾部下确界： $$ \overline{x}**_**n = \sup**_**{k\ge n}\{x_k\},\quad \underline{x}**_**n = \inf**_**{k\ge n}\{x_k\} $$ 1. $\{\overline{x}**_**n\}$ 单调递减，必有极限，定义为上极限： $$ \varlimsup**_**{n\to\infty} x_n = \lim_{n\to\infty}\sup_{k\ge n}x_k $$ 2. $\{\underline{x}**_**n\}$ 单调递增，必有极限，定义为下极限： $$ \varliminf**_**{n\to\infty} x_n = \lim_{n\to\infty}\inf_{k\ge n}x_k $$ ### 直观理解 不断砍掉前面有限项，只看剩下尾部全体项的上确界，这个上确界一路往下压稳定下来的值就是上极限； 尾部下确界一路往上抬稳定下来的值就是下极限。

**正项级数：**
若级数满足 $$ \forall n\in \mathbb{N}^*****,\quad u_n \ge 0 $$ 则称 $\displaystyle\sum_{n=1}^{\infty} u_n$ 为******正项级数**。 

> 说明：允许通项等于 $0$，严格大于 $0$ 只是特例；部分教材也将 $u_n>0$ 称作严格正项级数。

**交错级数：**

若级数的项正负交替出现，形如： $$ \sum_{n=1}^{\infty} (-1)^{n-1} u_n = u_1 - u_2 + u_3 - u_4 + \cdots $$ 其中 $\boldsymbol{u_n > 0}\ (n=1,2,3,\dots)$，称该级数为**交错级数**。 > 另一种等价形式： $$ \sum_{n=1}^{\infty} (-1)^{n} u_n = -u_1 + u_2 - u_3 + u_4 -\cdots,\quad u_n>0 $$ 两者只是整体符号相反，敛散性一致。

**绝对收敛 条件收敛**

**更序级数：**

设级数 $$ \sum_{n=1}^{\infty} u_n = u_1+u_2+u_3+\cdots $$ $\sigma:\mathbb{N}^*\to\mathbb{N}^*$ 是**正整数集上的一个双射（置换）**。 把原级数的项按照 $\sigma$ 的次序重新排列，得到新级数 $$ \sum_{n=1}^{\infty} u_{\sigma(n)} $$ 称这个级数为原级数的**更序级数（重排级数）**。

**柯西乘积：**

把二重和按**对角线分组**：固定 $k=i+j$，把所有满足 $i+j=k$ 的项合并在一起： $$ c_k=\sum_{i=0}^k a_i b_{k-i} $$ 定义**柯西乘积级数** $$ \boldsymbol{\left(\sum_{n=0}^\infty a_n\right)\left(\sum_{n=0}^\infty b_n\right) =\sum_{k=0}^{\infty} c_k =\sum_{k=0}^{\infty}\left(\sum_{i=0}^k a_i b_{k-i}\right)} $$ > 直观： > $$ \begin{aligned} c_0 &= a_0b_0\\ c_1 &= a_0b_1+a_1b_0\\ c_2 &= a_0b_2+a_1b_1+a_2b_0\\ c_3 &= a_0b_3+a_1b_2+a_2b_1+a_3b_0\\ &\dots \end{aligned} $$ > 几何理解：在 $i-j$ 平面上，点 $(i,j)$，$i+j=k$ 就是对角线；柯西乘积就是沿着对角线把项加起来。 ### 对比：其他排列方式 二重和 $\sum_{i,j\ge 0}a_i b_j$ 有很多种排列（重排）方式： 1. **柯西乘积**：按对角线 $i+j=k$ 分组（三角型） 2. 按矩形：先固定 $i$，对 $j$ 求和；或固定 $j$，对 $i$ 求和 3. 其他任意重排（任意顺序枚举全部 $(i,j)$） > 关键：**不同的排列，得到的级数和可以不一样**，这和数项级数重排定理是一脉相承。 

**正方形排列乘积**

### 性质

**若 $\displaystyle\sum_{k=1}^\infty u_k$ 收敛于 $S$，则 $$ \lim_{n\to\infty} R_n = \lim_{n\to\infty}(S - S_n) = 0 $$ 几何意义：累加项数越多，剩下没加的那部分总和无限趋近于0。**

**收敛，x_n的极限为0**

**$$ \sum_{n=1}^{\infty}ku_n = k\sum_{n=1}^{\infty}u_n = kS $$ $$ \sum_{n=1}^{\infty}(u_n\pm v_n) =\sum_{n=1}^{\infty}u_n \pm \sum_{n=1}^{\infty}v_n =S\pm T $$**

**将收敛级数各项任意分组加括号： $$ (u_1+\cdots+u_{n_1})+(u_{n_1+1}+\cdots+u_{n_2})+\cdots $$ 所得新级数收敛，和等于原级数的和。**

**极限点的集合上下确界都在集合中**

** $\{x_n\}$ 收敛 $\iff E$ 仅有单个元素，上下极限相等，等于数列极限。**

设实数列 $\{x_n\}$，记 $$ \varlimsup_{n\to\infty}x_n = A,\quad \varliminf_{n\to\infty}x_n = B $$

**上极限：**

同时满足以下两条：

 1. $\forall \varepsilon>0,\ \exists N\in\mathbb{N}^*****$，当 $n\ge N$ 时，恒有 $$ x_n < A+\varepsilon $$ 含义：下标充分大之后，所有项不会持续大于 $A+\varepsilon$，大于 $A+\varepsilon$ 的项仅有有限项； 

2. $\forall \varepsilon>0,\ \forall N\in\mathbb{N}^*****$，总 $\exists n\ge N$，使得 $$ x_n > A-\varepsilon $$ 含义：无论下标取多大起始位置，后面永远有无穷多项落在 $A-\varepsilon$ 上方。

**下极限：**

同时满足以下两条：

1. $\forall \varepsilon>0,\ \exists N\in\mathbb{N}^*****$，当 $n\ge N$ 时，恒有 $$ x_n > B-\varepsilon $$ 含义：下标充分大之后，所有项不会持续小于 $B-\varepsilon$，小于 $B-\varepsilon$ 的项仅有有限项；
2. $\forall \varepsilon>0,\ \forall N\in\mathbb{N}^*****$，总 $\exists n\ge N$，使得 $$ x_n < B+\varepsilon $$ 含义：无论下标取多大起始位置，后面永远有无穷多项落在 $B+\varepsilon$ 下方。

**不等式：**

$$ \begin{aligned} \varliminf_{n\to\infty}x_n +\varliminf_{n\to\infty}y_n &\le \varliminf_{n\to\infty}(x_n+y_n)\\ &\le \begin{cases} \varliminf x_n+\varlimsup y_n\\ \varlimsup x_n+\varliminf y_n \end{cases}\\ &\le \varlimsup_{n\to\infty}(x_n+y_n) \le \varlimsup_{n\to\infty}x_n +\varlimsup_{n\to\infty}y_n \end{aligned} $$ 特例：若其中一个数列极限存在，等号成立。 例：$\lim\limits_{n\to\infty}x_n = a$，则 $$ \begin{aligned} \varlimsup_{n\to\infty}(x_n+y_n) &= a+\varlimsup_{n\to\infty}y_n\\ \varliminf_{n\to\infty}(x_n+y_n) &= a+\varliminf_{n\to\infty}y_n \end{aligned} $$

非负数列乘法不等式（$x_n\ge0,\ y_n\ge0$）

$$ \begin{aligned} \varliminf x_n\cdot\varliminf y_n &\le \varliminf(x_n y_n) \le \begin{cases} \varliminf x_n\varlimsup y_n\\ \varlimsup x_n\varliminf y_n \end{cases}\\ &\le \varlimsup(x_n y_n) \le \varlimsup x_n\cdot\varlimsup y_n \end{aligned} $$ 同样，某一数列极限存在时，两端取等。

**正项级数的部分和数列单调递增**

**阿贝尔变换：（离散版本的分部积分）**

设两组数列： $\{a_n\},\ \{b_n\}$，记部分和 $$ B_k = b_1 + b_2 + \dots + b_k,\quad B_0 = 0 $$ 于是有： $$ b_k = B_k - B_{k-1} $$

$$ \sum_{k=1}^{n} a_k b_k = a_n B_n - \sum_{k=1}^{n-1} B_k (a_{k+1}-a_k) $$

**阿贝尔引理：**

若 1. $\{a_k\}$ 单调； 2. $|B_k|\le M,\ k=1,2,\dots,n$，即 $b_k$ 的部分和有界。 则 $$ \left|\sum_{k=1}^{n} a_k b_k\right| \le M\big(\,|a_1|+2|a_n|\,\big) $$

**柯西判别法或者达朗贝尔判别法判断绝对发散，则原级数发散**

**绝对收敛和条件收敛：**

对任意实数 $x_n$，定义 $$ \begin{cases} x_n^+=\max\{x_n,\,0\}\\[4pt] x_n^-=\max\{-x_n,\,0\} \end{cases} $$ 恒等式： $$ \boldsymbol{x_n = x_n^+ - x_n^-},\quad \boldsymbol{|x_n| = x_n^+ + x_n^-} $$ $x_n^+,x_n^-$ 恒为非负数列。 $\sum x_n^+$：原级数全部正项构成的级数； $\sum x_n^-$：原级数全部负项取绝对值后构成的级数。

若 $\sum x_n$ 绝对收敛，则 1. $\boldsymbol{\sum x_n^+}$ 与 $\boldsymbol{\sum x_n^-}$ 都收敛； 2. $$ \sum_{n=1}^\infty x_n = \sum x_n^+ - \sum x_n^-,\quad \sum_{n=1}^\infty |x_n| = \sum x_n^+ + \sum x_n^-. $$

条件收敛时 $$ \boldsymbol{\sum x_n^+ = +\infty},\quad \boldsymbol{\sum x_n^- = +\infty}. $$ 正项和发散到 $+\infty$，负项绝对值的和也发散到 $+\infty$。 $$ \sum x_n=\underbrace{\sum x_n^+}_{+\infty}-\underbrace{\sum x_n^-}_{+\infty} $$ $\infty-\infty$ 是不定式，有限结果来自两个无穷大的消去，消去方式会改变最终结果。

原级数**绝对收敛** > **定理**：若 $\displaystyle\sum_{n=1}^\infty u_n$ 绝对收敛，和为 $S$，则它的**任意更序级数也绝对收敛，并且和仍然等于 $S$**。 > 核心原因： > 用正部负部分解：$u_n=u_n^+-u_n^-$，$\sum u_n^+,\sum u_n^-$ 都是有限收敛正项级数。 > 重排只改变顺序，**正项全部加起来总和不变，负项绝对值总和也不变**，故 > $$ > \sum u_{\sigma(n)}=\sum u_{\sigma(n)}^+-\sum u_{\sigma(n)}^-=\sum u_n^+-\sum u_n^- = S > $$ > 绝对收敛级数：**顺序不影响总和**。

原级数**条件收敛**（黎曼重排定理） > **黎曼定理**：若 $\displaystyle\sum_{n=1}^\infty u_n$ 条件收敛，则： > 1. 对任意给定实数 $A$，存在一个更序级数，使得该更序级数收敛于 $A$； > 2. 也可以构造更序级数，使得它发散到 $+\infty$ 或者 $-\infty$； > 3. 甚至可以构造出**发散、振荡**的更序级数。 > 本质：条件收敛时 > $$ > \sum u_n^+=+\infty,\quad \sum u_n^-=+\infty > $$ > 两个无穷大，我们可以人为挑选正项、负项的先后，控制部分和走向。

**柯西收敛正常**

**绝对收敛的乘积（Mertens 第一定理）：**

若 $$ \sum_{n=0}^\infty a_n=A,\quad \sum_{n=0}^\infty b_n=B $$ **两个级数都绝对收敛**，则： 1. 二重级数 $\displaystyle\sum_{i=0}^\infty\sum_{j=0}^\infty |a_i b_j|$ 收敛； 2. 柯西乘积 $\sum c_k$ **绝对收敛**； 3. $$ \boldsymbol{\sum_{k=0}^\infty c_k = A\cdot B} $$ > 更强结论：**所有排列方式的重排级数，和都等于 $A\cdot B$**。 > 因为 $|a_i b_j|$ 构成的二重级数绝对收敛，任意重排不改变和。

**两个条件收敛级数相乘，柯西乘积可以发散。**

### 收敛准则

**柯西收敛准则：**

级数收敛 $\iff$ 对 $\forall \varepsilon>0$，总 $\exists N\in \mathbb{N}^*$，当 $n>N$ 时，对任意正整数 $p$，都有： $$ \left| u_{n+1}+u_{n+2}+\dots+u_{n+p} \right| < \varepsilon $$ ### 理解 足够靠后的任意长度一段余项之和的绝对值可以任意小，后面无限多项叠加不会累积出固定大小的增量。 

 等价写法（部分和视角） 记部分和 $S_n=\sum\limits_{k=1}^n u_k$，$\sum u_n$ 收敛 $\iff \{S_n\}$ 是柯西数列。

**正项级数收敛原理：**

单调有界定理直接给出： $$ \sum_{n=1}^\infty u_n \text{ 收敛} \iff \text{部分和数列 } \{S_n\} \text{ 有上界} $$ - 有上界：$\exists M>0,\forall n,\ S_n\le M$，$\{S_n\}$ 收敛，级数收敛； - 无上界：$S_n\to +\infty$，级数发散到 $+\infty$。

**比较判别法**：

设 $0\le u_n\le v_n$： 1. $\sum v_n$ 收敛 $\implies \sum u_n$ 收敛； 2. $\sum u_n$ 发散 $\implies \sum v_n$ 发散。

**极限形式：**

设 $\displaystyle\sum_{n=1}^{\infty} u_n$，$\displaystyle\sum_{n=1}^{\infty} v_n$ 均为**正项级数**，即 $$ u_n \ge 0,\ v_n > 0,\quad \forall n\in \mathbb{N}^* $$ 记极限 $$ \lim_{n\to\infty} \frac{u_n}{v_n} = l $$

情形1：$0 < l < +\infty$（极限为有限正常数）$$ \sum u_n \text{ 收敛} \iff \sum v_n \text{ 收敛} $$ 含义：$n\to\infty$ 时 $u_n$ 与 $v_n$ 是**同阶无穷小**，二者敛散性完全一致。

情形2：$l = 0$ $$ \lim_{n\to\infty}\frac{u_n}{v_n}=0 $$ 等价于 $u_n = o(v_n)\ (n\to\infty)$，$u_n$ 是比 $v_n$ 更高阶的无穷小： $$ \sum v_n \text{ 收敛} \implies \sum u_n \text{ 收敛} $$ $\sum v_n$ 发散时无法判定 $\sum u_n$。

情形3：$l = +\infty$ $$ \lim_{n\to\infty}\frac{u_n}{v_n}=+\infty $$ 等价于 $v_n = o(u_n)\ (n\to\infty)$，$v_n$ 是比 $u_n$ 更高阶的无穷小： $$ \sum v_n \text{ 发散} \implies \sum u_n \text{ 发散} $$ $\sum v_n$ 收敛时无法判定 $\sum u_n$。

**柯西判别：**

$\displaystyle\sum_{n=1}^{\infty} u_n$ 为正项级数：$u_n\ge 0,\ n=1,2,3,\dots$，计算上极限 $$ \varlimsup_{n\to\infty} \sqrt[n]{u_n} = \rho $$

1. $\boldsymbol{\rho < 1}$ 级数 $\displaystyle\sum_{n=1}^\infty u_n$ **收敛**；
2.   $\boldsymbol{\rho > 1}$（包含 $\rho=+\infty$） 级数 $\displaystyle\sum_{n=1}^\infty u_n$ **发散**；
3.   $\boldsymbol{\rho = 1}$ 判别法失效，无法判定敛散性，需要更换判别方式。

**比值判别法（达朗贝尔判别法）**：

$$ \lim_{n\to\infty}\frac{u_{n+1}}{u_n}=\rho $$ $$ \begin{cases} \rho<1,\text{ 收敛}\\ \rho>1,\text{ 发散}\\ \rho=1,\text{ 判别失效} \end{cases} $$

**拉阿伯判别法（Raabe判别法）：**

正项级数 $\displaystyle\sum_{n=1}^{\infty}u_n\ (u_n>0)$，当比值判别法、根式判别法算出极限 $\rho=1$ 失效时，采用Raabe判别法做精细判定。

记极限： $$ R=\lim_{n\to\infty}n\left( \frac{u_n}{u_{n+1}} - 1 \right) $$ 判定规则： 1. $R>1$：级数收敛； 2. $R<1$：级数发散； 3. $R=1$：Raabe判别法依旧失效，需要更高阶判别（高斯判别法）。

**积分判别法：**

设函数 $f(x)$ 在 $[1,+\infty)$ 上**非负、单调递减**， $$a_n = f(n),\quad n=1,2,3,\dots$$ 则正项级数 $\displaystyle\sum_{n=1}^{\infty} a_n$ 与反常积分 $\displaystyle\int_{1}^{+\infty} f(x)\mathrm{d}x$ **同敛散**。 $$ \sum_{n=1}^{\infty}a_n \text{收敛} \iff \int_{1}^{+\infty}f(x)\mathrm{d}x \text{收敛} $$ > 注意：仅敛散性相同，**级数的和不等于积分值**。

**绝对收敛，级数一定收敛**

(莱布尼兹级数)对于交错级数 $$ \sum_{n=1}^{\infty} (-1)^{n-1} u_n,\quad u_n>0 $$ 若满足两个条件： 1. $\{u_n\}$ 单调递减：$\boldsymbol{u_{n+1} \le u_n},\ \forall n\in \mathbb{N}^*$ 2. $\boldsymbol{\lim\limits_{n\to\infty} u_n = 0}$ 则交错级数 **收敛**，并且余项估计： $$ \big|R_n\big|=\left|\sum_{k=n+1}^{\infty} (-1)^{k-1}u_k\right| \le u_{n+1} $$ > 余项含义：用前 $n$ 项部分和 $S_n$ 近似级数和 $S$，误差绝对值不超过下一项 $u_{n+1}$。

**a ,b绝对收敛，则ab全排列绝对收敛，和相等**

**阿贝尔判别法：**

级数 $\displaystyle\sum_{k=1}^{\infty} a_k b_k$ 收敛，如果： 1. $\{a_n\}$ 单调有界； 2. $\displaystyle\sum_{n=1}^{\infty} b_n$ 收敛。

**狄利克雷判别法：**

级数 $\displaystyle\sum_{k=1}^{\infty} a_k b_k$ 收敛，如果： 1. $\{a_n\}$ 单调，且 $\lim\limits_{n\to\infty} a_n = 0$； 2. $\{b_n\}$ 的部分和序列 $B_n=\sum_{k=1}^n b_k$ 有界。

### 典例

**等比级数（几何级数）**：

$$ \sum_{n=0}^{\infty} q^n = 1 + q + q^2 + q^3 + \dots $$ 部分和： $$ S_n = \begin{cases} \displaystyle\frac{1-q^{n+1}}{1-q}, & q\neq 1\\ n+1, & q=1 \end{cases} $$ - $|q|<1$：$\lim\limits_{n\to\infty}S_n=\dfrac{1}{1-q}$，级数收敛； - $|q|\ge 1$：部分和极限不存在，级数发散。

**调和级数：**

$$ \sum_{n=1}^{\infty}\frac{1}{n}=1+\frac12+\frac13+\dots+\frac1n+\dots $$ 部分和 $S_n=\ln n+\gamma+o(1)$，$n\to\infty$ 时趋向 $+\infty$，级数发散。

**p级数：**

形如 $$ \sum_{n=1}^{\infty}\frac{1}{n^p}=1+\frac{1}{2^p}+\frac{1}{3^p}+\dots+\frac{1}{n^p}+\dots $$ 的数项级数称为**p-级数**，其中常数 $p\in\mathbb{R}$ 为参

$$ \begin{cases} p>1,\quad \displaystyle\sum_{n=1}^{\infty}\dfrac{1}{n^p}\ \text{收敛}\\ p\le 1,\quad \displaystyle\sum_{n=1}^{\infty}\dfrac{1}{n^p}\ \text{发散} \end{cases} $$

## 无穷乘积

### 定义

给定数列 $\{p_n\}$，**无穷多项相乘**： $$ \prod_{n=1}^{\infty} p_n = p_1 p_2 p_3\cdots $$

记部分乘积 $$ P_n=\prod_{k=1}^n p_k $$ - 若 $\lim\limits_{n\to\infty} P_n = P$，$P$ 是有限非零实数，则称**无穷乘积收敛**，乘积的值为 $P$。 - 若极限为 $0$，或者极限不存在，称无穷乘积**发散**。 > ⚠️重点：**无穷乘积收敛，极限不能是0！** > 只要部分乘积趋于0，统一算发散。 > 这是和级数很大的区别：级数允许和为0；无穷乘积收敛必须结果非零。

如果允许 $\prod p_n\to 0$ 算收敛，会破坏很多性质： 比如收敛无穷乘积要求通项 $p_n\to 1$，如果允许乘积趋于0，这个必要条件就不成立。

**绝对收敛：**

**$$ \boldsymbol{\prod_{n=1}^{\infty} p_n \text{ 收敛} \iff \sum_{n=1}^{\infty}\ln p_n \text{ 收敛}} $$**
对数收敛

### 性质

**若 $\displaystyle\prod_{n=1}^\infty p_n$ 收敛，则 $$ \boldsymbol{\lim_{n\to\infty} p_n = 1} $$**

**Wallis：**

$$ \boldsymbol{\frac{\pi}{2}=\prod_{n=1}^{\infty}\frac{4n^2}{4n^2-1}} $$ 拆开写： $$ \frac{\pi}{2}= \left(\frac{2}{1}\cdot\frac{2}{3}\right) \cdot\left(\frac{4}{3}\cdot\frac{4}{5}\right) \cdot\left(\frac{6}{5}\cdot\frac{6}{7}\right) \cdot\left(\frac{8}{7}\cdot\frac{8}{9}\right)\cdots $$ 也就是： $$ \frac{\pi}{2}= \frac{2}{1}\cdot\frac{2}{3}\cdot\frac{4}{3}\cdot\frac{4}{5}\cdot\frac{6}{5}\cdot\frac{6}{7}\cdots $$

**部分积极限为1**

### 收敛准则

**$$ \boldsymbol{\prod_{n=1}^{\infty} p_n \text{ 收敛} \iff \sum_{n=1}^{\infty}\ln p_n \text{ 收敛}} $$**

$$ \ln P_n=\sum_{k=1}^n \ln p_k $$ $P_n\to P>0 \iff \ln P_n\to \ln P$，即对数级数部分和收敛。 > 注意： > - $\prod p_n$ 收敛 $\iff \sum \ln p_n$ 收敛； > - 如果 $\sum\ln p_n=-\infty$，则 $P_n\to 0$，此时无穷乘积**发散**。

$p_n>0 \implies 1+a_n>0$，则 $$ \prod_{n=1}^\infty (1+a_n) \text{ 收敛} \iff \sum_{n=1}^\infty \ln(1+a_n)\text{ 收敛}. $$

当 $a_n\to 0$ 时，$\ln(1+a_n)\sim a_n\ (n\to\infty)$。 - 若 $a_n>0$：$\boldsymbol{\sum a_n}$ 收敛 $\iff \sum \ln(1+a_n)$ 收敛 $\iff \prod(1+a_n)$ 收敛。 > 即：$a_n>0$，$\prod(1+a_n)$ 收敛 $\iff \sum a_n$ 收敛。（若an不定号看平方）

## 拓展

### 欧拉常数

**欧拉常数的定义**

欧拉常数通常用希腊字母 **γ**（gamma）表示，其最经典的定义源于**调和级数与自然对数的极限差**：

$对于正整数 n，调和级数的前 n 项和为 \(H_n = 1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n}\)。当 n 趋向于无穷大时，\(H_n\) 会趋向于无穷（调和级数发散），但如果用 \(H_n\) 减去自然对数 \(\ln n\)，其差值会收敛到一个固定的常数，这个常数就是欧拉常数：$

$\(\gamma = \lim_{n \to +\infty} \left( H_n - \ln n \right) = \lim_{n \to +\infty} \left( 1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n} - \ln n \right)\)$

这一极限由瑞士数学家欧拉（Leonhard Euler）在 1734 年首次研究并确认收敛，意大利数学家马斯凯罗尼（Lorenzo Mascheroni）后来对其进行了更精确的计算，因此欧拉常数也被称为 “欧拉 - 马斯凯罗尼常数”。

### 超越数

**定义**

设一个数为 $\alpha$，若不存在满足以下条件的多项式 \(P(x)\)：

1. 多项式系数均为**整数**（或等价地，均为有理数）；
2. 多项式次数 \(n $\geq$ 1\)（即非零常数多项式）；
3. \(P($\alpha$) = 0\)（即 \($\alpha$\) 是该多项式的根）。

则称 \($\alpha$\) 为**超越数**。

与之相对的概念是 “代数数”：能满足上述多项式方程的数（包括所有有理数、部分无理数如 \(\sqrt{2}\)、\(\sqrt[3]{5}\) 等）。

**性质**：

**超越数一定是无理数，但无理数不一定是超越数**

### 龙格现象

#### 定义

对**区间上的等距节点高次多项式插值**：

当插值节点数量不断增加（插值多项式次数 n 越来越高）时，**区间内部**的逼近误差会变小，但**区间两端附近**的误差会急剧放大、曲线剧烈震荡，最终插值多项式严重偏离原函数。

这种**高次等距插值在区间端点附近剧烈振荡**的现象，就叫做**龙格现象**。核心前提：**等距节点 + 高次插值**，是数值分析里插值部分最经典的病态问题。
